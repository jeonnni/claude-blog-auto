# AI로 계약서 독소 조항 10분 만에 찾는 실무 프롬프트

## 제목 후보
1. AI로 계약서 독소 조항 10분 만에 찾는 실무 프롬프트
2. 복잡한 입찰 제안서 비교 분석 AI로 쉽게 하는 법
3. 챗GPT 클로드로 계약서 위험 조항 사전 감지하는 노하우

계약서나 입찰 제안서 검토할 때 페이지 수 많으면 머리부터 아프다.
글자도 빼곡해서 중요한 독소 조항 놓치기 십상인데.
요즘은 AI 활용해서 10분 만에 싹 훑는 편이다.
실무에서 바로 쓰는 프롬프트랑 노하우 몇 개 정리해봤다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20260906-1404-ai-10-diagram.png)
`사진 파일: 20260906-1404-ai-10-diagram.png`

우선 긴 계약서 전체를 그냥 던져주면 AI도 헛소리한다.
역할을 확실하게 정해줘야 답이 깔끔하게 나오더라.
"너는 10년 차 법무 실무자야. 수주사에 불리한 독소 조항만 찾아줘" 이렇게 지시하는 거다.
특히 손해배상 책임이나 지체상금 같은 부분은 금액 한도가 없는 경우가 많다.
프롬프트에 "무제한 책임, 일방적 계약 해지 조건 위주로 찾아줘"라고 적으면 바로 잡아낸다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20260906-1404-ai-10-compare.png)
`사진 파일: 20260906-1404-ai-10-compare.png`

입찰 제안서 비교할 때도 엄청 유용하다.
여러 업체 제안서를 표 하나로 정리해달라고 하면 금방 끝난다.
"A업체와 B업체의 기술 스펙, 단가, 유지보수 조건을 마크다운 비교표로 만들어줘"
이렇게 요청하면 눈에 쏙 들어오게 정리해주네.
사람이 눈으로 일일이 비교하면 서너 시간 걸릴 분량인데 1~2분이면 되더라.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260906-1404-ai-10-steps.png)
`사진 파일: 20260906-1404-ai-10-steps.png`

내가 주로 쓰는 검토 순서는 딱 3단계다.
1단계, 문서 파일(PDF나 텍스트)을 올리고 전체 요약을 요청한다.
2단계, 독소 조항 및 불리한 조건 추출 프롬프트를 입력한다.
3단계, AI가 걸러낸 위험 항목만 사람이 직접 원문과 대조한다.
AI가 찾아준 조항만 골라서 읽으니 검토 시간이 말도 안 되게 줄어든다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20260906-1404-ai-10-summary.png)
`사진 파일: 20260906-1404-ai-10-summary.png`

당연히 AI가 100% 완벽한 건 아니다.
대외비나 민감한 개인정보는 반드시 마스킹하고 올리는 게 안전하다.
최종 서명 전에는 법무팀이나 전문가 확인도 필수고.
그래도 1차 필터링용으로 활용해보면 칼퇴 확률이 대폭 올라간다.
오늘 처리해야 할 계약서나 제안서가 있다면 바로 한번 테스트해보자.
