# 엑셀 데이터 대조 10초 만에 끝내는 AI 프롬프트 작성법

## 제목 후보
1. 엑셀 데이터 대조 10초 만에 끝내는 AI 프롬프트 작성법
2. 영업 매출과 출고 내역 불일치, AI로 싹 잡아내는 법
3. 챗GPT로 엑셀 숫자가 안 맞을 때 오차만 추출하는 프롬프트

영업 매출표랑 물류 출고 내역 대조할 때 아직도 눈으로 하나씩 보는지 모르겠다.
VLOOKUP 돌려도 수량이나 금액 살짝 틀린 건 일일이 확인하기 귀찮더라.

요즘은 AI 활용해서 복사해 넣기만 하면 불일치 오차만 바로 뽑아낼 수 있다.
10초면 안 맞는 항목과 숫자가 다 나온다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261019-1725-10-ai-diagram.png)
`사진 파일: 20261019-1725-10-ai-diagram.png`

원리는 진짜 단순하다.
서로 다른 두 데이터를 AI한테 주고 "안 맞는 것만 찾아서 표로 만들어줘"라고 명령하는 거다.

근데 그냥 "대조해줘"라고만 입력하면 가끔 AI가 헛소리를 하더라.
그래서 오차만 정확히 짚어내도록 지시하는 검수 프롬프트가 필수다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261019-1725-10-ai-compare.png)
`사진 파일: 20261019-1725-10-ai-compare.png`

기존 수작업 방식이랑 AI 검수 방식을 비교해보면 차이가 확 난다.
직접 찾아낼 때는 수량 틀린 거 눈 빠지게 찾다가 놓치기 일쑤였다.
AI를 쓰면 불일치하는 품목이랑 수량 차이까지 표 한 장으로 깔끔하게 정리해준다.

내가 실제 데이터 대조할 때 쓰는 프롬프트 구조를 공유해본다.
필요할 때 복사해서 그대로 쓰면 된다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261019-1725-10-ai-steps.png)
`사진 파일: 20261019-1725-10-ai-steps.png`

작성 방법은 3단계만 기억하면 된다.

첫째, 역할 정의
"너는 10년 차 데이터 검수 전문가다. 제시된 두 자료를 엄격하게 비교해라."

둘째, 데이터 입력
[영업 매출 내역]과 [물류 출고 내역] 엑셀 데이터 전체를 텍스트로 붙여넣는다.

셋째, 조건 및 출력 형식 지정
"두 내역에서 품목명이 같지만 수량이나 금액이 일치하지 않는 항목만 찾아라.
결과는 [품목명 / 매출 수량 / 출고 수량 / 오차 / 비고] 형태의 표로 정리해라.
수량이 완벽히 일치하는 항목은 출력에서 완전히 제외해라."

이렇게 조건만 확실하게 적어주면 안 맞는 숫자가 10초 만에 튀어나온다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261019-1725-10-ai-summary.png)
`사진 파일: 20261019-1725-10-ai-summary.png`

월말마다 영업 매출이랑 출고 내역 안 맞아서 야근했다면 꼭 써봐라.
괜히 엑셀 함수 복잡하게 꼬아서 만드느라 고생할 필요가 전혀 없다.
프롬프트 하나만 템플릿으로 저장해두면 칼퇴할 수 있다.
오늘 당장 엑셀 데이터 긁어서 테스트해보자.
