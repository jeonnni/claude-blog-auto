# 매뉴얼만 넣으면 끝, 챗GPTs 생성해서 반복 업무 줄이는 방법

3. 자주 묻는 업무 질문, 챗GPT 활용법으로 싹 자동화하기

매일 출근해서 똑같은 사내 문의 답변하느라 시간 다 보내는 사람들 많다.

"연차 신청 어디서 해요?"
"비품 구매 결재는 누구한테 받나요?"

매뉴얼에 다 써있는 내용인데 왜 자꾸 물어보는지 모를 때가 많다.

근데 이거 챗GPTs 생성 기능 쓰면 10분 만에 해결되더라.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261102-0213-gpts-diagram.png)
`사진 파일: 20261102-0213-gpts-diagram.png`

쉽게 말해서 내 업무 자료만 따로 학습시킨 전용 챗봇을 만드는 거다.

기존에는 매번 프롬프트에 매뉴얼 복사해서 붙여넣고 질문해야 했다.

이게 생각보다 귀찮고 번거롭다.

하지만 GPTs 만들기를 해두면 매뉴얼 파일 하나만 올려놓고 필요할 때마다 검색하듯 물어보면 끝이다.

내가 일하지 않아도 AI가 알아서 매뉴얼 보고 답을 찾아준다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261102-0213-gpts-compare.png)
`사진 파일: 20261102-0213-gpts-compare.png`

일반 챗GPT 쓸 때랑 나만의 GPTs 만들어서 쓸 때 차이가 확실히 난다.

일반 챗GPT는 매번 배경 설명하고 파일 첨부해야 헛소리를 안 한다.

반면에 맞춤형 GPTs는 미리 매뉴얼을 파일로 넣어두니까 바로 정확한 답변이 나온다.

동료들한테 링크만 공유해주면 내가 일일이 대답해 줄 필요도 없다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261102-0213-gpts-steps.png)
`사진 파일: 20261102-0213-gpts-steps.png`

만드는 방법도 진짜 단순하다.

1. GPTs 작성 화면(Create)에 들어간다.
2. Configure 탭에서 챗봇 이름과 설명을 적는다.
3. Instructions 칸에 챗봇의 역할과 규칙을 입력한다.
4. Knowledge 부분에 PDF나 엑셀 매뉴얼 파일을 업로드한다.

Instructions에는 이렇게 적어주면 일을 잘한다.

"너는 우리 회사 사내 FAQ 전담 보조야. 아래 첨부된 매뉴얼 파일 문서에 기반해서만 답변해 줘. 문서에 없는 내용이면 모르겠다고 답변해."

이렇게 세팅해두면 소설 쓰지 않고 문서 내용만 딱 정리해서 알려준다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261102-0213-gpts-summary.png)
`사진 파일: 20261102-0213-gpts-summary.png`

💡 핵심 정리
- 파일 첨부(Knowledge)에 FAQ 엑셀이나 PDF 넣기
- Instructions에 '문서 기반 답변' 조건 꼭 붙이기
- 완성된 GPTs 링크를 사내에 공유하면 끝

자주 오는 문의 10개만 정리해서 올려봐라.

하루에도 몇 번씩 핑퐁되던 답변 업무가 한순간에 줄어든다.

오늘 퇴근 전에 딱 10분만 투자해서 하나 만들어두는 걸 추천한다.
