개발하다 보면 AI API 키를 프로젝트에 등록해서 쓸 일이 많다.
근데 GitHub 같은 곳에 실수로 코드 올렸다가 API 키 유출되는 경우가 생각보다 흔하다.

자고 일어났더니 토큰 엄청 소진되어 있고 결제 폭탄 맞았다는 글도 꽤 보인다.
미리 보안 설정이랑 지출 한도만 잡아둬도 이런 참사는 충분히 막을 수 있다.

기본적으로 API 키는 절대 코드 안에 직접 하드코딩하면 안 된다.
보통 실수하는 경로가 코드를 저장소에 공유하거나 올릴 때 키값까지 같이 올려버리는 거다.

환경 변수 파일인 .env 파일에 키를 따로 보관하는 게 기본이다.
그리고 .gitignore 파일에 .env를 꼭 추가해둬야 커밋할 때 안 올라간다.

비밀번호처럼 지켜야 하는 게 API 키다.
하지만 단순히 숨기는 걸로만 끝내면 살짝 불안하다.

만약 실수로 유출되더라도 피해를 최소화하는 장치가 필요하다.
그게 바로 비용 한도 설정(Spending Limit)이랑 주기적인 키 재발급이다.

한도 설정을 안 해두면 계정에 연결된 카드로 무단 자동 결제가 계속 들어간다.
반대로 한도를 걸어두면 일정 금액 이상 쓰였을 때 자동으로 차단된다.

설정하는 방법도 생각보다 엄청 간단하더라.

1. 콘솔 페이지 로그인 후 빌딩(Billing) 메뉴 접속
2. 한도 설정(Limits) 항목에서 월별 최대 지출 금액 입력
3. 기존 사용하던 API 키 주기에 맞춰 삭제하고 재발급

코드 예시도 간단하게 남겨둔다.

```
# .env 파일
CLAUDE_API_KEY=your_api_key_here
```

```
# .gitignore 파일
.env
```

이렇게 세팅해두면 개발할 때도 안전하고 키를 외부로 흘릴 일도 없다.
