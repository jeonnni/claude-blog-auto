원인은 간단하다.
앤트로픽이 최근 모델을 업데이트하면서 영문 직역투가 늘었거든.

한국어 데이터 학습 비율보다 글로벌 공통 데이터 비중이 커진 거다.

그래서 묘하게 말끝이 번역기 돌린 것처럼 뻗친다.

프롬프트에 조건을 걸어두는 거다.

첫째, 자연스러운 한국어 구어체를 써달라고 요청한다.
둘째, 번역투 문장을 쓰지 말라고 명시한다.
셋째, 내가 쓴 예시 문장을 하나 던져준다.
