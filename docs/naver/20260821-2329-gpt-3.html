요즘 AI로 문서 요약하고 메일 쓰느라 업무 속도 엄청 빨라졌다.
근데 막상 쓸 때 찜찜한 순간이 있더라.

회사 내부 매출 자료나 고객 정보 그대로 복사해서 넣어도 되나 싶은 거다.

결론부터 말하면 절대 그냥 넣으면 안 된다.
내가 입력한 데이터가 모델 학습에 쓰여서 다른 사람 답변에 툭 튀어나올 수도 있거든.

오늘은 안전하게 AI 쓰면서 칼퇴하는 보안 설정 3가지를 정리해 본다.

첫 번째, 학습용 데이터 제공 옵션 끄기다.

대부분 AI 서비스는 설정 메뉴에 들어가면 내 대화 내역을 모델 학습에 쓸지 말지 정하는 스위치가 있다.
이걸 끄면 내 대화가 서버에 영구적으로 남아 학습되는 걸 막아준다.

두 번째, 프롬프트 입력할 때 개인정보 비식별화하기다.

설정을 꺼도 입력창에 사람 이름, 전화번호, 계좌번호를 대놓고 넣는 건 위험하다.
이건 프롬프트 작성할 때 약간만 신경 쓰면 해결되네.

예를 들어 이렇게 바꿔서 입력하는 거다.

나쁜 예시:
"홍길동 팀장(010-1234-5678)에게 보낼 5월 매출 보고서 메일 써줘."

좋은 예시:
"[담당자명]([연락처])에게 보낼 [M월] 매출 보고서 메일 작성해 줘."

진짜 중요한 민감 정보는 아예 변수 형태로 치환해서 질문하는 게 안전하다.
AI는 맥락만 이해하면 되니까 치환된 단어로도 충분히 좋은 답을 만들어내더라.

세 번째, 임시 채팅 기능 활용하기다.

대화 기록 자체를 서버에 남기고 싶지 않다면 임시 대화 모드를 켜고 써야 한다.
창을 닫으면 대화 내용이 즉시 사라져서 흔적이 안 남는다.

설정 방법도 생각보다 엄청 간단하다.
프로필 클릭하고 설정 들어가서 클릭 몇 번이면 끝난다.

1. 설정(Settings) 메뉴 접속
2. 데이터 제어(Data Controls) 클릭
3. 모델 개선을 위한 학습 버튼 비활성화
