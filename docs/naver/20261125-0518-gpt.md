# 프로젝트 예산안 단가 계산 실수? 챗GPT 프롬프트로 싹 잡기

프로젝트 예산안이나 사업비 정산서 제출해본 적 있을 거다.
엑셀 수식 하나 잘못 걸어서 전체 금액 틀어진 경험 다들 한번쯤 있더라.

단가에 수량을 곱해야 하는데 빼기를 걸어놓거나 수식이 깨지는 경우가 많다.
손으로 일일이 돋보기 대고 검수하자니 눈도 아프고 시간도 너무 오래 걸린다.

요즘은 이런 단순 계산 오류나 항목 누락을 AI로 1분 만에 잡는다.
생각보다 정확도가 엄청 높아서 실무에 바로 써먹기 좋네.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261125-0518-gpt-diagram.png)
`사진 파일: 20261125-0518-gpt-diagram.png`

방법은 진짜 간단하다.
엑셀에 있는 예산표 영역을 그대로 드래그해서 AI 창에 붙여넣으면 된다.

근데 그냥 "검수해줘"라고만 쓰면 AI도 대충 보고 넘어간다.
원하는 검토 기준을 프롬프트로 명확하게 줘야 하더라.

내가 실제 업무에서 자주 쓰는 검수 프롬프트를 공유해본다.

[프롬프트 예시]
"아래는 프로젝트 예산표야.
1. [수량 x 단가 = 합계] 계산에 오류가 있는지 검증해줘.
2. 상위 항목 합계가 하위 항목의 총합과 일치하는지 확인해줘.
3. 비고란이나 필수 입력 항목 중 누락된 셀이 있는지 짚어줘.
오류가 발견된 행의 이름과 수정해야 할 금액을 정리해서 알려줘."

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261125-0518-gpt-compare.png)
`사진 파일: 20261125-0518-gpt-compare.png`

이렇게 프롬프트를 넣으면 엑셀 수식이 깨진 부분만 딱 짚어준다.
사람이 눈으로 찾을 땐 30분 넘게 걸리던 작업이다.

AI에 넣으니까 10초 만에 "3번 행 수량 5개, 단가 10,000원인데 합계가 50,000원이 아니라 5,000원으로 되어 있습니다"라고 찾아내더라.
수작업으로 볼 땐 절대 안 보이던 0 하나 빠진 게 바로 잡힌다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261125-0518-gpt-steps.png)
`사진 파일: 20261125-0518-gpt-steps.png`

특히 사업비 정산서 작성할 때 필수 항목 누락된 거 찾는 데 직빵이다.
증빙 번호나 사업자번호 빠진 칸도 귀신같이 찾아낸다.

요즘 AI 서비스들은 엑셀 파일(.xlsx)을 그대로 올려도 분석을 잘하더라.
텍스트 복사가 귀찮으면 그냥 파일 첨부하고 위 프롬프트만 던지면 끝이다.

제출 직전 마감 임박했을 때 쓸데없는 실수를 막아주는 가장 강력한 무기다.
엑셀 계산 미스로 식은땀 흘려본 경험 있다면 오늘 바로 써보자.
