직접 입력하면 영수증 10장에 20분은 족히 걸린다.

내가 자주 쓰는 프롬프트를 그대로 공유해본다.
따라 해보면 엄청 편할 거다.

1단계: 스마트폰으로 영수증이나 종이 문서를 밝은 곳에서 똑바로 찍는다.
2단계: AI 앱을 켜고 이미지 첨부 버튼을 누른다.
3단계: 아래 프롬프트를 그대로 복사해서 붙여넣는다.

"이 사진 속 영수증 내용을 엑셀에 붙여넣을 수 있게 표 형식으로 추출해줘.
열 이름은 [날짜, 항목명, 금액, 결제수단]으로 지정해주고, 숫자에는 천단위 쉼표를 넣어줘."

이렇게 입력하면 AI가 알아서 깔끔한 텍스트 표를 만들어준다.
그대로 드래그해서 엑셀에 붙여넣으면 끝난다.
