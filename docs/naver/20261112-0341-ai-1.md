# 복잡한 당직 스케줄표, AI 프롬프트 하나로 1분 만에 끝내는 법

## 제목 후보
1. 복잡한 당직 스케줄표, AI 프롬프트 하나로 1분 만에 끝내는 법
2. 휴가·연속근무 제약조건 다 넣고 챗GPT로 근무표 자동 생성하기
3. 엑셀 붙여넣기만 하면 끝! AI 당직표 작성 실무 프롬프트

매달 돌아오는 당직표 짜기.
솔직히 머리 터질 것 같다.

연차 쓰는 사람 피해야 하고.
주말 당직 겹치면 안 되고.
연속 근무 금지 조건까지 넣으면 엑셀 켜두고 한참을 멍하게 된다.

이거 AI한테 시키면 1분 만에 끝난다.
단, 조건만 제대로 던져주면 말이다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261112-0341-ai-1-compare.png)
`사진 파일: 20261112-0341-ai-1-compare.png`

보통 그냥 "이번 달 당직표 짜줘" 하면 AI도 대충 짜준다.
사람 이름 몇 개 빠지거나 연속 근무 걸려서 결국 손으로 다시 수정하게 되더라.

제대로 된 프롬프트를 써야 꼬임 없이 깔끔하게 나온다.

핵심은 조건표를 텍스트로 딱 정돈해서 주는 거다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261112-0341-ai-1-diagram.png)
`사진 파일: 20261112-0341-ai-1-diagram.png`

내가 자주 쓰는 프롬프트 구조는 간단하다.

1. 인원 목록
2. 근무 기간
3. 제약 사항 (연차, 주말 불가 등)
4. 출력 형식 (엑셀 복붙용 표 형태)

이 4가지만 맞춰서 작성하면 오류가 거의 안 난다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261112-0341-ai-1-steps.png)
`사진 파일: 20261112-0341-ai-1-steps.png`

실제 사용 예시 프롬프트다.
그대로 복사해서 조건만 바꿔 쓰면 된다.

[근무자]
김철수, 이영희, 박민수, 정수진, 최동현 (총 5명)

[기간]
다음 달 1일 ~ 30일 (매일 1명 당직)

[제약 조건]
1. 2일 연속 당직 절대 불가
2. 김철수: 5일~7일 휴가 (당직 제외)
3. 정수진: 주말 당직 불가
4. 5명 전체 당직 횟수는 최대한 균등하게 배분할 것

[출력]
날짜, 요일, 당직자 이름이 들어간 마크다운 표 형태로 작성해줘.

이렇게 붙여넣으면 10초 만에 표가 만들어진다.

나온 결과를 복사해서 엑셀에 붙여넣기만 하면 끝이다.

진짜 손으로 짤 때보다 시간 절약이 수십 배는 된다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261112-0341-ai-1-summary.png)
`사진 파일: 20261112-0341-ai-1-summary.png`

AI 업무 자동화가 별거 없다.
내가 고생하던 걸 프롬프트 몇 줄로 줄이는 게 핵심이다.

복잡한 근무표 때문에 스트레스받지 말고
오늘 당장 이 프롬프트로 당직표 만들어보자.
