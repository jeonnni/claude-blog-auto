작성 방법은 3단계만 기억하면 된다.

첫째, 역할 정의
"너는 10년 차 데이터 검수 전문가다. 제시된 두 자료를 엄격하게 비교해라."

둘째, 데이터 입력
[영업 매출 내역]과 [물류 출고 내역] 엑셀 데이터 전체를 텍스트로 붙여넣는다.

셋째, 조건 및 출력 형식 지정
"두 내역에서 품목명이 같지만 수량이나 금액이 일치하지 않는 항목만 찾아라.
결과는 [품목명 / 매출 수량 / 출고 수량 / 오차 / 비고] 형태의 표로 정리해라.
수량이 완벽히 일치하는 항목은 출력에서 완전히 제외해라."

이렇게 조건만 확실하게 적어주면 안 맞는 숫자가 10초 만에 튀어나온다.
