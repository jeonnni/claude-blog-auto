# 내 PC에서 직접 일하는 AI, 클로드 디스패치 사용법

## 제목 후보
1. 내 PC에서 직접 일하는 AI, 클로드 디스패치 사용법
2. 복잡한 설정 없이 업무 자동화 끝내는 Claude Dispatch
3. 단순 답변 넘어 파일까지 제어하는 클로드 디스패치 활용 가이드

요즘 생성형 AI로 일하는 사람들 정말 많다.
근데 매번 챗창에 파일 첨부하고 복붙하는 것도 일이다.

원래 AI가 내 컴퓨터에 있는 파일이나 프로그램까지 다루진 못했으니까.

근데 최근에 나온 클로드 디스패치는 완전히 다르더라.

말 그대로 AI가 내 PC 안에서 직접 업무를 수행하는 개념이다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20260821-1829-pc-ai-diagram.png)
`사진 파일: 20260821-1829-pc-ai-diagram.png`

작동 방식은 생각보다 간단하다.

클로드에게 명령을 내리면 내 컴퓨터의 로컬 환경에 직접 접근한다.
폴더를 열어서 파일을 읽고, 정리하고, 알아서 결과물까지 만들어낸다.

중간에서 사람이 일일이 대화창으로 옮겨 적을 필요가 없다는 거다.

개발자만 쓰던 복잡한 API나 파이썬 스크립트 몰라도 된다.
설정 자체가 엄청 직관적으로 바뀌었거든.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20260821-1829-pc-ai-compare.png)
`사진 파일: 20260821-1829-pc-ai-compare.png`

기존 생성형 AI 추천 방식이랑 비교해 보면 차이가 확실하다.

예전에는 웹 브라우저 안에서만 노는 챗봇 느낌이었다.
엑셀 정리해달라고 하면 코드만 짜주고, 내가 직접 실행해야 했다.

반면에 Claude Dispatch는 실행까지 내 PC에서 직접 해버린다.

엑셀 파일 수정, 파일명 일괄 변경, 문서 요약 저장까지 알아서 끝낸다.
실무 생산성이 안 오를 수가 없는 구조다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260821-1829-pc-ai-steps.png)
`사진 파일: 20260821-1829-pc-ai-steps.png`

그럼 어떻게 쓰는지도 알려줄게.

첫 번째, 클로드 디스패치 기능을 켜고 내 PC의 작업 폴더 권한을 연결한다.
안전을 위해 딱 지정한 폴더 안에서만 작동하도록 설정할 수 있다.

두 번째, 평소처럼 자연어로 요청 사항을 입력한다.
"이 폴더 안에 있는 텍스트 파일 다 합쳐서 하나의 요약본으로 만들어줘" 같이.

세 번째, AI가 스스로 실행하는 과정을 지켜보거나 다른 일을 한다.
작업이 끝나면 결과 파일이 폴더에 예쁘게 들어와 있네.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20260821-1829-pc-ai-summary.png)
`사진 파일: 20260821-1829-pc-ai-summary.png`

정리하자면 반복적인 컴퓨터 단순 작업이 많은 직장인한테 필수템이다.

매번 데이터 다운받아서 AI한테 전달하고 다시 받아오는 번거로움이 싹 사라진다.
진짜 내 컴퓨터 안에 일 잘하는 막내 부사수 한 명 들어온 기분이랄까.

AI 업무 자동화 생각 중이었다면 지금 바로 Claude Dispatch 시작해보는 걸 추천한다.
