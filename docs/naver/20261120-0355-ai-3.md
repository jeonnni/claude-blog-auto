# 수십 페이지 증권 보고서, AI로 3분 만에 핵심 리스크 뽑는 법

## 제목 후보
1. 수십 페이지 증권 보고서, AI로 3분 만에 핵심 리스크 뽑는 법

3. 주식 리서치 보고서 AI 요약 프롬프트, 목표주가 근거 3분 분석

증권사 리서치 보고서 매번 끝까지 읽기 진짜 힘들다.

보통 20페이지, 많게는 50페이지가 넘어가니까.

목표 주가만 슬쩍 보고 넘어가다가는.

매수 이유도 모른 채 물리기 십상이다.

요즘 다들 AI로 문서 요약 많이 하더라.

근데 그냥 "이 보고서 요약해줘"라고 입력하면.

쓸데없는 서론만 길게 뽑아준다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261120-0355-ai-3-diagram.png)
`사진 파일: 20261120-0355-ai-3-diagram.png`

투자할 때 필요한 핵심만 3분 만에 쏙 빼먹으려면.

프롬프트를 딱 구체적으로 잡아줘야 한다.

1. 목표 주가 산정 근거
2. 매출 및 영업이익 전망치
3. 보고서에 숨겨진 핵심 리스크

이 3가지만 제대로 요구해도 분석 시간이 확 줄어든다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261120-0355-ai-3-compare.png)
`사진 파일: 20261120-0355-ai-3-compare.png`

그냥 요약해달라고 했을 때랑.

투자용 프롬프트를 지정해서 넣었을 때 차이가 엄청 크더라.

일반 요약은 상투적인 산업 개요만 늘어놓는데.

투자 프롬프트를 쓰면 내가 진짜 필요한 숫자랑 악재만 딱 집어준다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261120-0355-ai-3-steps.png)
`사진 파일: 20261120-0355-ai-3-steps.png`

내가 실제로 쓰는 프롬프트 공유해본다.

보고서 파일 올려두고 이렇게 그대로 복사해서 써보자.

📌 [투자 리서치 3분 분석 프롬프트]
"네 역할은 증권사 수석 애널리스트다.
첨부된 리서치 보고서를 읽고 다음 항목만 작성해줘.
1. 제시된 목표주가와 구체적 근거 3가지
2. 올해 및 내년 예상 매출액과 영업이익 전망
3. 기업이 면한 가장 큰 리스크 요인 2가지
4. 한 줄 총평"

이렇게 질문 던지면.

쓸데없는 미사여구 다 빼고 딱 필요한 리스트로 정리해준다.

특히 리스크 요인은 보고서 뒷부분에 조그맣게 적혀있는 경우가 많은데.

AI가 이걸 진짜 잘 찾아내더라.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261120-0355-ai-3-summary.png)
`사진 파일: 20261120-0355-ai-3-summary.png`

주식 투자할 때 보고서 다 읽을 시간은 없지만.

남 말만 듣고 투자할 수는 없다.

보고서 첨부하고 이 프롬프트 하나만 딱 던져보자.

오늘부터 리서치 분석 시간이 10분의 1로 줄어들 거다.
