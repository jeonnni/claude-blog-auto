챗GPT 쓸 때 매번 똑같은 프롬프트 입력하느라 답답했던 적 있을 거다.

메모장에 작성해 둔 서식을 매번 찾아서 복사하고 붙여넣는 것도 일이다.

조금만 조건이 달라져도 다시 프롬프트 수정하느라 시간 다 지나간다.

이런 번거로운 과정을 클릭 한 번으로 끝내는 방법이 있다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261108-0210-gpt-1-aiprm-diagram.png)
`사진 파일: 20261108-0210-gpt-1-aiprm-diagram.png`

보통은 원하는 답변을 얻으려고 배경 설명부터 출력 형식까지 길게 쓴다.

매번 이 작업을 반복하다 보면 AI 쓰다가 피로감이 먼저 쌓인다.

확장프로그램 AIPRM을 써보면 이 과정이 싹 사라지더라.

자주 쓰는 전용 서식을 등록해 두고 클릭 한 번으로 바로 호출하는 방식이다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261108-0210-gpt-1-aiprm-compare.png)
`사진 파일: 20261108-0210-gpt-1-aiprm-compare.png`

기존 방식과 비교해 보면 작업 속도 차이가 꽤 크다.

메모장 뒤적거리며 복붙할 때는 준비 시간만 3~5분씩 걸렸다.

반면에 프롬프트 라이브러리에 올려두면 1초 만에 작업 준비가 끝난다.

하루에도 수십 번씩 AI를 쓰는 사람에게는 체감 차이가 엄청나다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261108-0210-gpt-1-aiprm-steps.png)
`사진 파일: 20261108-0210-gpt-1-aiprm-steps.png`

사용법도 생각보다 아주 간단하다.

크롬 웹스토어에서 AIPRM 확장프로그램을 설치하고 챗GPT에 접속하면 끝이다.

화면에 바로 수많은 템플릿과 저장 공간이 생긴다.

내가 자주 쓰는 프롬프트 예시를 하나 저장해 두면 편하다.

"[역할: 블로그 마케터] 아래 주제로 SNS 포스팅 문구 3가지를 작성해 줘. 조건: 친근한 말투, 3줄 요약 포함"

이렇게 세팅해 두면 다음부터는 단어 하나만 바꿔서 바로 결과를 뽑을 수 있다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261108-0210-gpt-1-aiprm-summary.png)
`사진 파일: 20261108-0210-gpt-1-aiprm-summary.png`

매번 프롬프트 만드느라 고민할 필요가 전혀 없다.

자주 쓰는 양식 몇 개만 등록해 둬도 AI 업무 생산성이 확 올라간다.

챗GPT 쓸 때 복사 붙여넣기 반복하고 있었다면 당장 써보길 추천한다.
