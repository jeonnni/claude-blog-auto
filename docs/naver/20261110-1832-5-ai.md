# 팀원 인사평가 피드백, 감정 빼고 5분 만에 다듬는 AI 프롬프트

## 제목 후보
1. 팀원 인사평가 피드백, 감정 빼고 5분 만에 다듬는 AI 프롬프트
2. 성과 피드백 작성할 때 주관을 빼주는 AI 비즈니스 글쓰기 팁
3. 인사평가 작성 스트레스 끝! AI로 객관적인 피드백 완성하기

연말이나 분기 말만 되면 인사평가 시즌이 찾아온다.
팀원들 성과 피드백 쓰다 보면 은근히 머리가 아프다.

괜히 주관적인 감정이 들어간 것 같기도 하고.
비즈니스 언어로 깔끔하게 정리하기가 생각보다 어렵더라.

"일처리가 답답함", "소통이 부족함" 이렇게 쓸 수는 없으니까.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261110-1832-5-ai-diagram.png)
`사진 파일: 20261110-1832-5-ai-diagram.png`

결국 피드백의 핵심은 팩트 중심의 객관화다.
구체적인 행동과 데이터만 남기고 감정적인 표현은 싹 덜어내야 한다.

이걸 매번 고민해서 쓰려면 시간도 오래 걸리는데.
요즘은 AI 프롬프트 하나로 5분 만에 정리하곤 한다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261110-1832-5-ai-compare.png)
`사진 파일: 20261110-1832-5-ai-compare.png`

일반적인 내 생각을 적은 텍스트와 AI를 거친 텍스트의 차이는 생각보다 크다.

예를 들어 "팀원 A는 보고서 작성이 늦고 오탈자가 많음" 이렇게 적어서 AI에 넣는다.
그러면 AI가 바로 건조하고 건설적인 비즈니스 언어로 바꿔준다.

"기한 내 보고서 제출율 향상이 필요하며, 문서 정밀도 검수 프로세스 보완이 권장됨"처럼 다듬어진다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261110-1832-5-ai-steps.png)
`사진 파일: 20261110-1832-5-ai-steps.png`

직접 써먹기 좋은 프롬프트 작성 순서다.

첫째, 팀원의 주요 성과 데이터와 아쉬운 점을 메모하듯 적는다.
둘째, 프롬프트에 '감정 배제', '건설적 피드백', '비즈니스 톤' 조건을 넣는다.
셋째, 출력된 초안을 보고 실제 상황에 맞게 살짝 수정만 하면 끝이다.

프롬프트 예시:
"아래 메모를 기반으로 인사평가 피드백을 작성해줘.
조건: 1. 주관적 판단이나 감정 표현 제외 2. 팩트 기반의 객관적 비즈니스 언어 사용 3. 향후 개선 방향 포함"

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261110-1832-5-ai-summary.png)
`사진 파일: 20261110-1832-5-ai-summary.png`

솔직히 피드백 쓰는 시간이 절반 이하로 줄었다.
무엇보다 피드백받는 팀원도 기분 상하지 않고 수긍하게 되더라.

이번 평가 시즌에는 끙끙 앓지 말고 AI 프롬프트를 활용해 보자.
퇴근 시간이 확실히 달라진다.
