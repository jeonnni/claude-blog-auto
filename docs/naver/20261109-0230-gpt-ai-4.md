# 챗GPT 클로드 쓸 때 내 데이터 유출 막는 AI 보안 설정 4가지

## 제목 후보
1. 챗GPT 클로드 쓸 때 내 데이터 유출 막는 AI 보안 설정 4가지
2. AI에 회사 문서 그대로 넣으면 위험한 이유와 필수 보안 수칙
3. 챗GPT 개인정보 학습 차단하는 방법과 프롬프트 작성 노하우

요즘 업무할 때 챗GPT나 클로드 안 쓰는 사람이 없다.

보고서 요약부터 코드 작성까지 진짜 편하긴 하더라.

근데 쓰다 보면 문득 불안해질 때가 있다.

회사 내부 문서나 고객 정보 넣어도 괜찮은 걸까?

생각 없이 복붙했다가 데이터가 AI 학습에 쓰일 수 있거든.

나중에 다른 사람 답변에 내 데이터가 튀어나올 수도 있다는 소리다.

오늘은 당장 따라 할 수 있는 AI 보안 수칙 4가지를 정리해본다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261109-0230-gpt-ai-4-diagram.png)
`사진 파일: 20261109-0230-gpt-ai-4-diagram.png`

첫 번째, 데이터 학습 비활성화(Opt-out) 끄기.

대부분 AI 서비스는 기본 설정이 '대화 내역 학습 허용'으로 되어 있더라.

내가 입력한 질문과 문서가 AI 성능 향상에 쓰인다는 뜻이다.

이걸 끄는 게 보안의 기본이다.

챗GPT든 클로드든 설정(Settings) 메뉴에 들어가 보면 데이터 제어 항목이 있다.

대화 기록 저장이나 모델 학습에 사용하지 않겠다는 옵션을 끄면 끝이다.

이것만 해둬도 내 대화가 재학습되는 위험을 크게 줄일 수 있네.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261109-0230-gpt-ai-4-compare.png)
`사진 파일: 20261109-0230-gpt-ai-4-compare.png`

두 번째, 민감한 개인정보는 변수로 치환하기.

실무에서 제일 많이 하는 실수가 실명과 연락처를 그대로 넣는 거다.

텍스트를 붙여넣기 전에 살짝 가공하는 습관이 필요하다.

예를 들어 '홍길동 / 010-1234-5678' 대신 '[고객A] / [연락처1]'로 바꿔서 던지는 거다.

매출 수치도 마찬가지다.

'2024년 매출 15억' 대신 '[A연도] 매출 [N억]'으로 입력하고 분석 결과를 받은 뒤 나중에 직접 수치를 대입하면 된다.

번거로워 보여도 막상 해보면 몇 초 안 걸리더라.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261109-0230-gpt-ai-4-steps.png)
`사진 파일: 20261109-0230-gpt-ai-4-steps.png`

세 번째, 파일 업로드 시 민감 데이터 사전 삭제.

요즘 AI는 PDF나 엑셀 파일 통째로 올려도 분석을 척척 해준다.

편하다고 회사 원본 파일 그대로 올리면 절대 안 된다.

파일 속성에 남아있는 작성자 정보나 숨겨진 시트, 민감한 고객 목록은 삭제하고 올리자.

필요한 텍스트나 표 부분만 따로 복사해서 가공 후 올리는 게 안전하다.

네 번째, 프롬프트에 보안 지침 직접 명시하기.

질문을 던질 때 프롬프트 맨 위에 한 줄을 덧붙이는 방법이다.

'이 데이터는 일회성 분석용이며 수집 및 학습하지 마라'고 지침을 주는 거다.

AI가 이 지침을 완벽히 법적으로 지키는 건 아니지만, 대화 맥락 안에서 내부 데이터 유출을 방지하는 조언을 생성하는 데 도움을 주더라.

🔹 오늘 당장 해야 할 일 정리
1. AI 서비스 설정에서 대화 학습 비활성화 끄기
2. 이름, 전화번호, 매출액은 기호나 변수로 바꿔서 입력하기
3. 원본 문서 파일 통째로 올리지 않기
