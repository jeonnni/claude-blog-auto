# 챗GPT 쓸 때마다 '격식 있게 써줘' 반복 입력 그만하는 법

## 제목 후보
1. 챗GPT 쓸 때마다 '격식 있게 써줘' 반복 입력 그만하는 법
2. 매번 프롬프트 입력하기 귀찮다면? 챗GPT 맞춤설정 3분 세팅
3. 챗GPT가 내 직무와 말투를 항상 기억하게 만드는 커스텀 인스트럭션 활용법

챗GPT한테 일 시킬 때 매번 똑같은 말 붙이는 사람들 많다.

"보고서용으로 격식 있게 작성해줘."
"결론부터 3줄 요약해줘."
"나는 마케터니까 마케팅 관점에서 답변해줘."

매번 새 대화창 열 때마다 이거 입력하는 거, 솔직히 귀찮더라.

한두 번도 아니고 매번 반복하다 보면 은근 시간 잡아먹는다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261121-0352-gpt-compare.png)
`사진 파일: 20261121-0352-gpt-compare.png`

이 귀찮은 과정을 싹 없애주는 기능이 있다.

바로 '맞춤 설정(Custom Instructions)'이다.

쉽게 말해 챗GPT한테 내 프로필과 원하는 답변 스타일을 미리 입력해두는 거다.

한 번만 설정해두면 다음부터는 알아서 내가 원하는 톤과 형식으로 답해준다.

설정 안 했을 때랑 했을 때 차이가 진짜 크더라.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261121-0352-gpt-diagram.png)
`사진 파일: 20261121-0352-gpt-diagram.png`

원리는 의외로 간단하다.

기존에는 [질문 + 내 직무 설명 + 답변 스타일 요청]을 매번 한 번에 던졌다면,

맞춤 설정을 켜두면 [내 직무/답변 스타일]이 배경에 기본으로 깔린다.

나는 그냥 진짜 물어보고 싶은 '본론 질문'만 딱 던지면 끝난다.

AI가 나를 미리 파악하고 답변을 내놓는 구조다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261121-0352-gpt-steps.png)
`사진 파일: 20261121-0352-gpt-steps.png`

세팅하는 방법도 3분이면 끝난다.

좌측 하단 프로필 아이콘 클릭하고 '맞춤 설정'으로 들어간다.

입력창은 딱 두 개가 나온다.

첫 번째 창에는 '내가 어떤 사람인지' 쓴다.
예시:
"나는 5년 차 기획자야. 주요 업무는 신사업 기획과 보고서 작성이야."

두 번째 창에는 '챗GPT가 어떻게 답해주길 바라는지' 쓴다.
예시:
"1. 두두등장 같은 쓸데없는 서론 빼고 본론부터 말해줘."
"2. 보고서에 바로 쓸 수 있게 격식 있는 어조로 써줘."
"3. 핵심 내용은 개조식(bullet point)으로 요약해줘."

이렇게 적고 저장 버튼 누르면 세팅 끝이다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261121-0352-gpt-summary.png)
`사진 파일: 20261121-0352-gpt-summary.png`

🎯 오늘의 핵심 요약

1. 매번 말투나 직무 설명 입력할 필요 없다.
2. 맞춤 설정 하나로 기본 답변 톤을 고정할 수 있다.
3. 한번 세팅해두면 업무 속도가 훨씬 빨라진다.

챗GPT 제대로 쓰려면 이 설정부터 먼저 해두는 게 좋다.
