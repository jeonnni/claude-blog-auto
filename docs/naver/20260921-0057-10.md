# 말로 다 되는 바이브 코딩으로 업무 자동화 툴 10분 만에 만들기

## 제목 후보
1. 코딩 몰라도 10분 만에 끝내는 나만의 웹 계산기 만들기
2. 말로 다 되는 바이브 코딩으로 업무 자동화 툴 10분 만에 만들기
3. 챗GPT로 코딩 없이 업무용 Web 계산기 만드는 법

매번 엑셀 켜서 복잡한 계산식 두드리는 거, 솔직히 귀찮다.

팀원들이나 고객한테 공유할 때도 파일 전달하고 설명하기 번거롭고.

요즘은 코딩 한 줄 몰라도 필요한 웹 도구를 바로 만든다.

이걸 '바이브 코딩'이라고 부르더라.

개발 지식 전혀 없이 그냥 AI한테 말로 설명만 하면 끝난다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20260921-0057-10-diagram.png)
`사진 파일: 20260921-0057-10-diagram.png`

작동하는 방식도 진짜 단순하다.

내가 원하는 화면이랑 기능을 AI한테 말로 적어준다.

그러면 AI가 웹페이지 코드 전체를 한 번에 짜준다.

그걸 웹 브라우저로 띄우기만 하면 나만의 계산기가 완성된다.

단 10분도 안 걸린다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20260921-0057-10-compare.png)
`사진 파일: 20260921-0057-10-compare.png`

기존 코딩이랑 비교해보면 차이가 확실히 체감된다.

예전에는 HTML, CSS, 자바스크립트 공부하느라 며칠씩 걸렸다.

수식 하나 바꾸려면 구글링하고 오류 잡느라 스트레스받았는데.

바이브 코딩은 그냥 채팅창에 수식만 바꿔달라고 말하면 된다.

오류가 나도 "에러 나는데 고쳐줘" 하면 알아서 바로 수정해준다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260921-0057-10-steps.png)
`사진 파일: 20260921-0057-10-steps.png`

직접 따라 할 수 있는 프롬프트 예시를 하나 가져왔다.

챗GPT나 AI 채팅창에 이렇게 적어보자.

"할인율과 수수료를 계산하는 웹 계산기 만들어줘."
"1. 원가, 할인율(%), 플랫폼 수수료(%) 입력 칸 만들기"
"2. 최종 판매가와 정산 금액, 마진율을 한눈에 보여주기"
"3. 깔끔한 디자인으로 하나의 HTML 파일로 작성해줘."

이렇게 요청하면 코드 블록 전체가 나온다.

메모장에 붙여넣고 확장자를 .html로 저장한 뒤 클릭하면 웹 브라우저에서 바로 뜬다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20260921-0057-10-summary.png)
`사진 파일: 20260921-0057-10-summary.png`

영업팀 견적 계산기나 마케팅 ROI 계산기 같은 거 매번 만들기 번거로웠다면 꼭 해보자.

어려운 프로그래밍 개념 배울 필요가 전혀 없다.

말만 잘 던지면 나에게 딱 맞는 맞춤형 업무 자동화 툴이 뚝딱 나온다.

오늘 퇴근 전에 딱 10분만 투자해서 직접 만들어보는 걸 추천한다.
