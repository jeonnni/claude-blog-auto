나 같은 경우 긴 문서 정리나 블로그 글 쓸 때는 클로드를 주로 쓴다.
챗GPT보다 덜 딱딱하고 사람 글처럼 부드럽게 써주거든.

클로드 유료 차이는 긴 글을 다룰 때 확실히 느껴진다.

예를 들어 프롬프트를 이런 식으로 던진다.

"이 보고서 내용을 단순 요약하지 말고, 팀장님께 보고할 핵심 상안 3가지로 다시 작성해 줘."

이렇게 지시하면 결과물 수정할 일이 확 줄어든다.

반면에 복잡한 데이터 분석이나 코딩 오류 찾을 땐 챗GPT 유료 결제가 돈값 한다.
에러 코드 복붙해서 던져두면 원인부터 해결법까지 깔끔하게 집어주네.

제미나이 어드밴스드는 구글 드라이브나 메일이랑 연동해서 자료 찾을 때 제일 편하더라.
