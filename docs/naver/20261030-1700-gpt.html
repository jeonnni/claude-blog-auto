계정 잠김 예방하는 3단계 안전 수칙이다.

1. VPN 끄고 동일한 접속 환경 유지하기.

2. 위험 키워드 직접 입력 피하기.
우회 공격이나 취약점 점검 프롬프트는 자동 감지 필터에 잘 걸린다.

3. 결제 정보와 계정 명의 일치시키기.
타인 카드로 결제하면 보안 시스템에서 오남용 계정으로 분류한다.
