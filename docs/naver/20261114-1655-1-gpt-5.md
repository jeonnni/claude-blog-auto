# 코딩 1도 몰라도 챗GPT로 5분 만에 나만의 업무 웹툴 만들기

## 제목 후보
1. 코딩 1도 몰라도 챗GPT로 5분 만에 나만의 업무 웹툴 만들기
2. 개발자 없이 챗GPT 바이브 코딩으로 단순 반복 업무 끝내는 법
3. 비개발자가 챗GPT 웹프로그램 만들어 업무 자동화한 후기

매일 반복되는 텍스트 변환이나 계산 작업할 때 은근히 짜증날 때가 많다.

개발팀에 만들어달라고 하기엔 너무 소소하고.
직접 코딩을 배우자니 엄두가 안 나더라.

근데 요즘은 코딩 한 줄 몰라도 챗GPT로 나만의 업무용 웹 프로그램을 만들 수 있다.

거창한 프로그램이 아니라, 딱 내 업무에 필요한 기능만 가진 툴이다.
텍스트로 원하는 걸 지시하기만 하면 뚝딱 만들어주는데, 이걸 바이브 코딩이라고 부르더라.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261114-1655-1-gpt-5-diagram.png)
`사진 파일: 20261114-1655-1-gpt-5-diagram.png`

작동 흐름도 진짜 간단하다.

내가 필요한 기능을 정리해서 챗GPT한테 말로 설명한다.
그럼 AI가 코드 전체를 짜준다.
그 코드를 메모장에 붙여넣고 파일로 저장하면 내 전용 웹 툴이 완성된다.

컴퓨터에 아무것도 설치할 필요가 없어서 비개발자한테 딱이더라.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261114-1655-1-gpt-5-compare.png)
`사진 파일: 20261114-1655-1-gpt-5-compare.png`

기존에 엑셀 함수 꼬이고 수작업하느라 시간 버리던 거랑 비교해 보면 차이가 크다.

기존엔 프로그램 하나 만드려면 외주를 맡기거나 몇 달 공부해야 했다.
반면에 바이브 코딩은 5분 만에 완성된다.
쓰다가 수정하고 싶은 부분이 생겨도 "버튼 색깔 바꿔줘" 하고 다시 요청하면 끝이다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261114-1655-1-gpt-5-steps.png)
`사진 파일: 20261114-1655-1-gpt-5-steps.png`

실제로 쓸 수 있는 챗GPT 프롬프트 작성법이다.
그대로 복사해서 지시어만 바꿔서 써보자.

1. 역할과 목표 지정
"너는 웹 개발자야. 내가 입력한 텍스트에서 이메일 주소만 추출하는 웹 프로그램을 만들어줘."

2. 화면 구성 요청
"화면 중앙에 입력창과 추출 버튼을 두고, 결과는 상자에 깔끔하게 보이게 해줘."

3. 코드 형태 지정
"HTML, CSS, 자바스크립트를 하나의 HTML 파일 코드 블록으로 작성해 줘. 메모장에 붙여넣어 바로 쓸 수 있게 해줘."

이렇게 던지면 알아서 완전한 코드를 출력해 준다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261114-1655-1-gpt-5-summary.png)
`사진 파일: 20261114-1655-1-gpt-5-summary.png`

출력된 코드를 메모장에 붙여넣고 확장자를 .html 로 저장하면 끝이다.
파일을 더블클릭하면 크롬이나 웨일 브라우저에서 바로 실행된다.

매일 복사 붙여넣기 하느라 스트레스받았던 일들, 이제 나만의 웹 툴로 자동화해보자.
작은 툴 하나 만드는 데 5분도 안 걸린다.
오늘 업무 중에 제일 귀찮았던 일부터 하나 바꿔보는 걸 추천한다.
