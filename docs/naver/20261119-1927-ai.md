요즘 업무할 때 AI로 보고서 초안 많이들 뽑아둔다.
나도 일단 빠르게 뼈대 만들 때는 AI부터 켜는데.

근데 막상 나온 초안을 읽어보면 답답할 때가 많다.
말만 그럴듯하고 속은 비어있는 느낌?

글은 길게 썼는데 핵심 논리가 꼬여있거나.
상사가 물어볼 만한 핵심 내용이 쏙 빠져있기도 하더라.

결국 그거 다듬고 고치느라 시간 다 보내고.
이럴 거면 처음부터 내가 쓸 걸 싶을 때도 많았다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261119-1927-ai-diagram.png)
`사진 파일: 20261119-1927-ai-diagram.png`

그래서 요즘은 초안 뽑고 나서 바로 수정 안 한다.
AI한테 직접 자기 글을 검수하게 만든다.

이걸 'AI 역검수'라고 부르는데.
AI한테 '악마의 대변인' 역할을 주는 거다.

단순히 "이 글 깔끔하게 고쳐줘"라고 하면 문장만 미사여구로 바꾼다.
근데 관점을 바꿔서 공격해보라고 지시하면 완전히 다른 반응이 나오더라.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261119-1927-ai-compare.png)
`사진 파일: 20261119-1927-ai-compare.png`

일반적인 수정 요청이랑 역검수 프롬프트는 결과물 차이가 크다.

일반 지시는 오탈자나 어색한 표현 정도만 잡는다.
반면에 역검수를 시키면 근거가 부족한 부실한 주장이나 누락된 핵심 항목을 스스로 짚어내더라.

내가 주로 쓰는 프롬프트 패턴을 몇 개 공유해본다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261119-1927-ai-steps.png)
`사진 파일: 20261119-1927-ai-steps.png`

첫째, 약점 찾기 단계다.
"네가 방금 작성한 글에서 논리적으로 가장 약한 주장 3가지를 찾아서 비판해줘."
이렇게 던지면 AI가 자기가 쓴 글의 구멍을 스스로 인정한다.

둘째, 반박 예측 단계다.
"이 보고서를 보고 깐깐한 상사나 고객이 던질 만한 날카로운 질문 5개만 뽑아줘."
이 질문 목록만 봐도 보완해야 할 점이 딱 보인다.

셋째, 누락 항목 보완 단계다.
"이 주장을 뒷받침하기 위해 추가해야 할 핵심 데이터나 개념은 뭐야?"
빠진 내용을 AI가 직접 찾아주니까 보완하기가 훨씬 쉽다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261119-1927-ai-summary.png)

AI로 보고서 쓸 때 초안 수정하느라 시간 다 버리지 말자.
스스로 검토하고 자기 논리를 깨부수게 만들면 끝난다.

오늘 작성하는 보고서에 역검수 프롬프트 한 줄만 추가해보자.
