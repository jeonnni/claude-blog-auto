내가 자주 쓰는 프롬프트 구조는 간단하다.

1. 인원 목록
2. 근무 기간
3. 제약 사항 (연차, 주말 불가 등)
4. 출력 형식 (엑셀 복붙용 표 형태)

이 4가지만 맞춰서 작성하면 오류가 거의 안 난다.

실제 사용 예시 프롬프트다.
그대로 복사해서 조건만 바꿔 쓰면 된다.

[근무자]
김철수, 이영희, 박민수, 정수진, 최동현 (총 5명)

[기간]
다음 달 1일 ~ 30일 (매일 1명 당직)

[제약 조건]
1. 2일 연속 당직 절대 불가
2. 김철수: 5일~7일 휴가 (당직 제외)
3. 정수진: 주말 당직 불가
4. 5명 전체 당직 횟수는 최대한 균등하게 배분할 것

[출력]
날짜, 요일, 당직자 이름이 들어간 마크다운 표 형태로 작성해줘.

이렇게 붙여넣으면 10초 만에 표가 만들어진다.

나온 결과를 복사해서 엑셀에 붙여넣기만 하면 끝이다.

진짜 손으로 짤 때보다 시간 절약이 수십 배는 된다.
