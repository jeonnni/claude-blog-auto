# 흩어진 엑셀 시트 합치기, 챗GPT 프롬프트 몇 줄이면 끝

월말만 되면 부서별로 흩어진 엑셀 파일 받아서 취합하느라 정신없다.
열 순서도 다르고 양식도 제각각이라 수동으로 붙여넣다 보면 1시간이 금방 지나가더라.

VLOOKUP이나 INDEX MATCH 같은 복잡한 함수 외울 필요 전혀 없다.
요즘은 챗GPT에 파일만 업로드하고 명령어 몇 줄 적으면 3분 만에 깔끔하게 합쳐준다.

매번 노가다 작업하느라 퇴근 늦어지던 사람한테는 진짜 신세계다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20260901-1527-gpt-diagram.png)
`사진 파일: 20260901-1527-gpt-diagram.png`

챗GPT 업무자동화의 핵심은 간단하다.
흩어져 있는 엑셀 시트들을 챗GPT가 읽고, 동일한 데이터 항목끼리 짝을 맞춰 보고서용 통합 표로 재구성하는 방식이다.

기존 수작업 방식이랑 비교해 보면 작업 시간 차이가 진짜 엄청나다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20260901-1527-gpt-compare.png)
`사진 파일: 20260901-1527-gpt-compare.png`

직접 수식 입력하고 피벗테이블 돌릴 때는 괄호 하나 틀려서 오류 찾아내느라 눈 빠지는 줄 알았다.
챗GPT 엑셀 활용법을 알고 나서는 텍스트 프롬프트 한 줄로 정제가 끝나버린다.

실제로 따라 할 수 있는 프롬프트 작성 순서를 정리해봤다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260901-1527-gpt-steps.png)
`사진 파일: 20260901-1527-gpt-steps.png`

첫 번째, 취합할 엑셀 파일이나 시트 데이터를 챗GPT 대화창에 올린다.

두 번째, 내가 원하는 취합 규칙을 구체적으로 알려준다.
이때 예시 프롬프트를 이렇게 작성하면 좋다.

"첨부한 3개 시트의 데이터에서 '날짜', '지점명', '매출액' 열만 골라내서 하나로 합쳐줘. 그리고 지점별 합계를 구해서 내림차순 정렬된 표 형태로 보여줘."

세 번째, 챗GPT가 생성해 준 결과 표를 그대로 복사해서 엑셀에 붙여넣거나 CSV 파일로 다운로드하면 끝이다.

복잡한 엑셀 함수 AI한테 맡기면 진짜 편해진다.
양식이 조금씩 달라도 챗GPT가 문맥을 이해해서 알아서 정리해 주니까 엑셀 보고서 자동화가 별거 아니더라.

오늘 퇴근 전 5분만 투자해서 바로 적용해봐라.
