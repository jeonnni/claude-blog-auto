# 챗GPT 클로드 쓸 때 내 데이터 학습 안 되게 막는 법

## 제목 후보
1. 챗GPT 클로드 쓸 때 내 데이터 학습 안 되게 막는 법
2. 회사 기밀 유출 없이 AI 쓰는 보안 설정 & 프롬프트 팁
3. 사내 AI 보안 사고 막는 데이터 익명화 프롬프트 작성법

요즘 회사 업무할 때 생성형 AI 안 쓰는 사람이 거의 없다.
근데 보고서나 이메일 초안 짤 때 회사 내부 자료를 무심코 넣다가 아차 싶을 때가 있더라.
내가 입력한 데이터가 모델 학습에 들어가면 자칫 사내 기밀 유출로 이어질 수 있다.
그렇다고 업무 효율 엄청 올라가는 AI를 아예 안 쓸 수도 없는 노릇이다.
결국 핵심은 내 데이터를 AI 학습에서 제외하고, 입력할 때 민감 정보를 익명화하는 거다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20260913-0044-gpt-diagram.png)
`사진 파일: 20260913-0044-gpt-diagram.png`

가장 먼저 해야 할 일은 계정별 보안 설정이다.
기본값으로 그냥 쓰면 내가 주고받은 대화가 모델 재학습에 쓰일 수 있네.
챗GPT나 클로드 같은 주요 서비스들은 대부분 학습 거부 기능을 제공한다.
이거 끄는 데 10초도 안 걸린다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260913-0044-gpt-steps.png)
`사진 파일: 20260913-0044-gpt-steps.png`

설정 순서는 생각보다 간단하다.

챗GPT 기준:
1. 왼쪽 아래 프로필 클릭 후 Settings 들어간다.
2. Data Controls 메뉴를 찾는다.
3. 'Improve the model for everyone' 옵션을 끔으로 바꾼다.

클로드 기준:
1. 계정 프로필 클릭 후 Privacy 설정으로 이동한다.
2. 데이터 학습 활용 동의 항목을 해제한다.

이렇게 옵트아웃을 해두면 내 입력값이 모델 개선 학습에 쓰이지 않는다.

하지만 설정만 바꿨다고 100% 안심할 순 없다.
대화 창에 직접 민감한 정보를 넣는 습관 자체를 바꿔야 하더라.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20260913-0044-gpt-compare.png)
`사진 파일: 20260913-0044-gpt-compare.png`

가장 많이 하는 실수가 실제 고객사 이름이나 프로젝트명, 매출 금액을 그대로 복붙하는 거다.

[위험한 프롬프트]
"OO전자 3분기 매출 500억 달성 관련 성과 보고서 써줘."

[안전한 프롬프트]
"A사 최근 분기 매출 N00억 달성 관련 성과 보고서 초안 짜줘. 회사명과 수치는 비식별화했어."

고유명사는 'A사', 'B 프로젝트'처럼 알파벳이나 가상 이름으로 바꿔라.
금액이나 전화번호, 주민번호 같은 개인정보도 전부 치환해서 넣는 게 안전하다.
자주 쓰는 비식별화 프롬프트 템플릿 하나 만들어두면 업무할 때 진짜 유용하더라.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20260913-0044-gpt-summary.png)
`사진 파일: 20260913-0044-gpt-summary.png`

사내 AI 보안 수칙, 어렵게 생각할 필요 전혀 없다.

1. 계정 설정에서 데이터 학습 거부(Opt-out) 켜기.
2. 프롬프트 넣기 전 회사명, 숫자, 개인정보 익명화하기.

이 두 가지만 지켜도 보안 사고 걱정 없이 안전하게 AI 쓸 수 있다.
지금 바로 내 계정 보안 설정부터 확인해보자.
