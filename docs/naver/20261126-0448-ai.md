웹 브라우저 켜면 탭만 몇 십 개 쌓여 있는 사람 많더라.
나도 그랬다.

메일 쓰다가 AI 켜고.
문서 읽다가 번역기 켜고.
그러다 보면 탭 찾다가 시간 다 간다.

근데 데스크톱 전용 앱 쓰고 나서부터는 브라우저를 안 연다.

단축키 하나 누르면 바로 AI 창이 뜬다.
작업 흐름이 전혀 안 깨지더라.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261126-0448-ai-diagram.png)
`사진 파일: 20261126-0448-ai-diagram.png`

보통 AI 쓸 때 어떻게 하나.

브라우저 열고, 즐겨찾기 누르고, 접속 기다리고.
이 과정만 해도 10초 넘게 걸린다.

근데 데스크톱 앱은 다르다.

Alt + Space 같은 단축키 한번 누르면 화면 중앙에 창이 떠오른다.
작업하던 화면 그대로 둔 채로 바로 질문 던지면 끝이다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261126-0448-ai-compare.png)
`사진 파일: 20261126-0448-ai-compare.png`

클로드 데스크톱이나 챗GPT 데스크톱 앱 둘 다 비슷하게 동작하더라.

요즘은 시스템 단축키를 지원하는 AI 생산성 앱들이 정말 잘 나온다.

가장 편리한 건 화면 캡처 연동이다.

영문 문서나 오류 화면 보다가 막히면?
그냥 단축키로 영역 캡처하고 바로 붙여넣은 다음 이렇게 써본다.

"이 에러 메시지 원인이랑 해결법 세 줄 요약해줘."

그러면 3초 만에 답변이 나온다.
브라우저 탭 옮겨 다니던 시절로 절대 못 돌아간다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261126-0448-ai-steps.png)
`사진 파일: 20261126-0448-ai-steps.png`

설정 방법도 진짜 단순하다.

1. 전용 데스크톱 앱을 설치한다.
2. 설정 메뉴 들어가서 단축키(Shortcut) 항목을 찾는다.
3. 본인 손에 가장 익숙한 단축키로 지정한다.

나는 Alt + Space 조합이 제일 편하더라.
손이 기억해서 작업 중에 바로바로 불러온다.

실제로 자주 쓰는 프롬프트 예시 하나 남겨둔다.

"지금 캡처해서 붙인 텍스트 자연스러운 비즈니스 이메일 톤으로 바꿔줘."

이거 하나만 활용해도 문서 작업 속도가 3배는 올라간다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261126-0448-ai-summary.png)
`사진 파일: 20261126-0448-ai-summary.png`

PC 작업할 때 AI 탭 찾느라 허우적대지 마라.

단축키 하나 세팅해두면 업무 몰입도가 완전히 달라진다.

오늘 당장 데스크톱 앱 깔고 단축키부터 지정해보자.
