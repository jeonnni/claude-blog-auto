# 코딩 몰라도 됨! AI한테 대화로 프로그램 만드는 법

2. 코딩 몰라도 됨! AI한테 대화로 프로그램 만드는 법
3. 단순 반복 업무 끝, 비개발자의 바이브코딩 실전 활용법

매일 반복되는 엑셀 작업이나 파일 정리.
솔직히 너무 귀찮다.

남들은 파이썬으로 자동화한다는데.
문과생에 비개발자라면 엄두도 안 나는 게 사실이다.

근데 요즘은 코드를 직접 안 짜도 된다.
그냥 AI한테 말로 설명만 하면 끝난다.

이걸 요즘 '바이브 코딩'이라고 부르더라.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20260823-1125-ai-diagram.png)
`사진 파일: 20260823-1125-ai-diagram.png`

바이브 코딩이 별거 없다.
진짜 말 그대로 느낌(Vibe)만 던져주는 거다.

"매일 아침 폴더에 들어오는 엑셀 파일들 합쳐줘"
"PDF에서 텍스트만 뽑아서 리스트로 만들어줘"

외주 개발자한테 요구사항 말하듯이 챗봇에 치면 알아서 코드를 짜준다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20260823-1125-ai-compare.png)
`사진 파일: 20260823-1125-ai-compare.png`

기존 코딩이랑 제일 큰 차이는 공부할 필요가 없다는 점이다.

예전엔 문법 배우고 환경 설정하다가 포기했는데.
이젠 질문 몇 번으로 바로 실행 가능한 도구가 나온다.

실제로 내가 써먹은 프롬프트는 이런 식이다.

"파이썬으로 특정 폴더 안의 이미지 파일명을 오늘 날짜로 싹 바꿔주는 프로그램 만들어줘. 실행 방법도 왕초보용으로 알려줘."

이렇게 보내면 알아서 코드랑 실행 방법까지 친절하게 알려준다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260823-1125-ai-steps.png)
`사진 파일: 20260823-1125-ai-steps.png`

만약 에러가 난다?
그것도 걱정할 필요가 없다.

터미널이나 까만 창에 뜬 빨간 에러 메시지.
그냥 드래그해서 AI한테 다시 던지면 된다.

"이런 에러 나는데 어떻게 고쳐?"

그럼 AI가 자기 코드를 스스로 수정해 준다.
우리는 그냥 복사해서 붙여넣기만 계속하면 끝이다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20260823-1125-ai-summary.png)
`사진 파일: 20260823-1125-ai-summary.png`

핵심은 거창한 프로그램을 만들려고 하지 않는 거다.
내 일상 업무 중에서 딱 10분 줄여줄 도구부터 시작하면 된다.

복잡한 언어 배운다고 책 사지 말고.
오늘 바로 AI한테 평소 귀찮았던 일 하나만 시켜보자.

삶의 질이 진짜 달라진다.
