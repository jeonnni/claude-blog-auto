# 3초 만에 끝나는 종이 문서·영수증 엑셀 정리 (챗GPT 이미지 분석)

## 제목 후보
1. 종이 문서 사진 찍어서 엑셀로 바로 넣는 방법 (AI OCR 활용)
2. 영수증 수백 장 일일이 입력하지 마세요: 사진 텍스트 엑셀 변환 팁
3. 3초 만에 끝나는 종이 문서·영수증 엑셀 정리 (챗GPT 이미지 분석)

책상 위에 쌓인 영수증이랑 종이 문서.
일일이 보면서 엑셀에 타이핑하다 보면 눈도 아프고 시간도 금방 간다.

나도 얼마 전까지는 일일이 직접 입력했었다.
숫자 하나 틀려서 다시 확인하고 수정하는 작업이 정말 귀찮더라.

근데 요즘은 스마트폰으로 사진 한 장 딱 찍어서 끝낸다.
AI가 알아서 텍스트를 읽고 엑셀 표 형태로 만들어주거든.

정말 3초면 깔끔하게 정돈된다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20260912-1357-3-gpt-diagram.png)
`사진 파일: 20260912-1357-3-gpt-diagram.png`

작동 원리는 별거 없다.
휴대폰 카메라로 촬영하고 AI에 이미지 올린 뒤 표로 만들어달라고 하면 끝이다.

옛날 OCR 프로그램들은 오타도 많고 서식이 다 깨져서 손이 더 많이 갔다.
근데 요즘 AI 이미지 분석 기능은 문맥까지 이해하더라.

구겨진 영수증이나 약간 비뚤게 찍힌 종이도 알아서 잘 읽어낸다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20260912-1357-3-gpt-compare.png)
`사진 파일: 20260912-1357-3-gpt-compare.png`

손으로 직접 입력할 때랑 AI를 쓸 때 차이가 너무 크다.

직접 입력하면 영수증 10장에 20분은 족히 걸린다.
오타 검수까지 하려면 금방 지치기 마련이다.

반면에 AI 텍스트 추출을 쓰면 10장이든 20장이든 순식간이다.
심지어 원하는 표 규칙을 지정해 주면 엑셀에 바로 붙여넣을 수 있게 뽑아준다.

방법도 진짜 간단하다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260912-1357-3-gpt-steps.png)
`사진 파일: 20260912-1357-3-gpt-steps.png`

내가 자주 쓰는 프롬프트를 그대로 공유해본다.
따라 해보면 엄청 편할 거다.

1단계: 스마트폰으로 영수증이나 종이 문서를 밝은 곳에서 똑바로 찍는다.
2단계: AI 앱을 켜고 이미지 첨부 버튼을 누른다.
3단계: 아래 프롬프트를 그대로 복사해서 붙여넣는다.

"이 사진 속 영수증 내용을 엑셀에 붙여넣을 수 있게 표 형식으로 추출해줘.
열 이름은 [날짜, 항목명, 금액, 결제수단]으로 지정해주고, 숫자에는 천단위 쉼표를 넣어줘."

이렇게 입력하면 AI가 알아서 깔끔한 텍스트 표를 만들어준다.
그대로 드래그해서 엑셀에 붙여넣으면 끝난다.

글자가 살짝 뭉개진 영수증은 "확실하지 않은 글자는 [?] 표시해줘" 라고 덧붙이면 나중에 확인하기 편하더라.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20260912-1357-3-gpt-summary.png)

매달 지출 결의서 쓰거나 종이 문서 정리해야 할 때 꼭 써봐라.
타이핑 노가다에서 완전히 벗어날 수 있다.

스마트폰 하나로 문서 정리 시간 90%는 줄어들 거다.
