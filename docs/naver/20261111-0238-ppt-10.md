보고서 쓰려고 컴퓨터 켜면 한숨부터 나온다.
PPT 켜고 슬라이드 레이아웃 잡느라 30분.
엑셀 켜서 표 그리고 숫자 맞추느라 또 30분.

정작 중요한 기획은 시작도 못 했는데 시간 다 간다.

요즘은 AI 화면 안에서 화이트보드랑 시트 작업이 다 되더라.
엑셀이나 PPT 안 켜고 10분 만에 끝내는 노하우 공유해본다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261111-0238-ppt-10-diagram.png)
`사진 파일: 20261111-0238-ppt-10-diagram.png`

작업 흐름은 생각보다 훨씬 간단하다.
머릿속 아이디어를 대충 던지면 AI가 알아서 구도를 잡는다.

핵심은 텍스트로만 받아내려고 하지 않는 거다.
화이트보드 형태로 전체 구조를 먼저 그리라고 해야 된다.

예를 들면 이렇게 프롬프트를 던져보자.

"이번 신제품 마케팅 기획안 작성하려고 해.
전체 보고서 구조를 화이트보드 형태로 시각화해줘."

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261111-0238-ppt-10-compare.png)
`사진 파일: 20261111-0238-ppt-10-compare.png`

기존에는 엑셀이랑 PPT를 왔다 갔다 하느라 정신없었다.
근데 화면 하나에서 다 처리하니까 몰입도가 확실히 다르다.

표 작업도 훨씬 간단해졌다.
데이터 정리해달라고 하면 알아서 깔끔한 시트로 뽑아준다.

"최근 3개월 채널별 유입 데이터 정리해서
수정이 가능한 시트 형태로 출력해줘."

이렇게 요청하면 몇 초 만에 데이터 표가 완성된다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261111-0238-ppt-10-steps.png)
`사진 파일: 20261111-0238-ppt-10-steps.png`

실제로 업무에 쓸 때 추천하는 순서다.

첫째, 화이트보드로 전체 목차랑 뼈대 잡기.
둘째, 필요한 수치 데이터 시트로 변환하기.
셋째, 완성된 시트에서 바로 수정하고 정리하기.

이제 오피스 프로그램 켜서 일일이 서식 맞추던 때로 못 돌아갈 것 같다.

📌 핵심 요약

1. PPT나 엑셀 프로그램 없이 창 하나로 모든 작업 종료.
2. 화이트보드 기능으로 아이디어 시각화와 보고서 뼈대 구성.
3. 시트 기능으로 데이터 정리와 실시간 수정까지 한 번에 해결.
