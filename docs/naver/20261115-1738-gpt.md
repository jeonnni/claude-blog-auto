# 수십 페이지 공고문, 챗GPT 프롬프트 하나로 지원자격 서류 체크 끝내기

## 제목 후보
1. 정부지원사업 공고문 50페이지짜리 AI로 1분 만에 분석하는 법
2. 수십 페이지 공고문, 챗GPT 프롬프트 하나로 지원자격 서류 체크 끝내기
3. 지원금 신청 서류 빠뜨리지 않는 AI 공고문 요약 프롬프트 활용 팁

정부지원사업 공고문 뜯어보다가 지친 적 많을 거다.

보통 30페이지, 길게는 50페이지 넘어가는 PDF 파일 하나 던져주는데.
읽다 보면 우리 회사가 지원 대상이 맞는지도 헷갈리고.

무엇보다 서류 하나 빠뜨려서 탈락하면 그것만큼 억울한 게 없다.

요즘은 AI 프롬프트 하나만 잘 짜두면 이 작업이 1분 만에 끝난다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261115-1738-gpt-diagram.png)
`사진 파일: 20261115-1738-gpt-diagram.png`

핵심은 공고문 전체를 통째로 넘기면서 '조건부 추출'을 시키는 거다.

그냥 "이 문서 요약해줘"라고 하면 수박 겉핥기 식으로 끝난다.
결국 지원 자격이나 필수 서류가 누락되더라.

그래서 질문할 때 기준을 정확히 정해줘야 한다.

내가 매번 쓰는 프롬프트 양식은 이렇다.

---
[내 사업장 정보]
- 업종: IT 서비스업
- 업력: 3년 차 (창업기업)
- 매출액: 2억 원
- 지역: 서울특별시

[요청사항]
위 사업장 정보를 바탕으로 첨부된 공고문을 분석해줘.
1. 지원 가능 여부 (가장 중요한 제한/제외 요건 체크)
2. 제출 서류 목록 (필수 서류 / 우대 가점 서류 구분)
3. 신청 마감일 및 신청 방법
---

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261115-1738-gpt-compare.png)
`사진 파일: 20261115-1738-gpt-compare.png`

직접 눈으로 훑을 때랑 AI한테 프롬프트를 줬을 때 차이가 꽤 크다.

사람이 읽으면 세부 항목에 있는 '신청 제외 대상' 조항을 놓치기 쉽다.
게다가 필수 첨부서류에 서명이 빠졌는지 같은 세부 사항도 헷갈리고.

반면에 프롬프트를 정교하게 던지면 AI가 자격 요건과 제출 서류를 표로 딱 정리해준다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261115-1738-gpt-steps.png)
`사진 파일: 20261115-1738-gpt-steps.png`

실제로 업무에 적용할 때는 딱 3단계만 기억하면 된다.

첫째, 사업 공고문 PDF를 준비한다.
둘째, 내 사업장 정보와 원하는 출력 양식을 넣은 프롬프트를 작성한다.
셋째, AI가 뽑아준 체크리스트를 보고 필수 서류만 챙긴다.

이렇게만 해도 공고문 읽는 시간이 1시간에서 1분으로 줄어든다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261115-1738-gpt-summary.png)
`사진 파일: 20261115-1738-gpt-summary.png`

수십 페이지 공고문 들여다보느라 진 빼지 말자.

기본 자격 검수랑 제출 서류 체크리스트는 AI한테 맡기고.
우리는 사업계획서 내용 깎는 데 시간에 더 투자하는 게 훨씬 남는 장사다.

오늘 당장 다음 지원사업 공고문 나오면 프롬프트 덧붙여서 올려보자.
일하는 속도가 확실히 달라질 거다.
