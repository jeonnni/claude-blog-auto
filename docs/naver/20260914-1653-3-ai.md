수많은 서류에 영수증, 증빙 자료까지 대조하다 보면 눈도 피로하고 오탈자 꼭 하나씩 놓치더라.

사람이 직접 하면 한 시간 넘게 걸리는 서류 검수.
AI한테 맡기면 단 3초 만에 끝난다.

근데 그냥 "서류 검수해줘" 하면 제대로 안 잡아준다.
원하는 핵심을 딱 집어서 프롬프트를 짜야 된다.

AI 서류 검수 흐름은 생각보다 간단하다.
원본 데이터와 비교 대상을 붙여넣고 검토 기준만 명확히 지정해 주면 끝이다.

어려운 코딩 같은 거 몰라도 된다.
텍스트만 복사해서 던져주면 알아서 오탈자랑 숫자 불일치를 찾아낸다.

`사진 파일: 20260914-1653-3-ai-compare.png`

눈으로 일일이 볼 때랑 AI를 쓸 때 차이가 너무 크더라.
특히 금액 숫자가 맞는지 대조할 때 진짜 편하다.

실제로 활용하기 좋은 프롬프트 구조를 공유해본다.
그대로 복사해서 업무에 써먹어보자.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260914-1653-3-ai-steps.png)
`사진 파일: 20260914-1653-3-ai-steps.png`

[프롬프트 작성 방법]

1. 역할 부여: "너는 꼼꼼한 문서 검수 전문가야."

2. 검수 대상 제공: [원본 서류 내용] / [비교 서류 내용]

3. 검수 항목 지정:
- 인적사항(이름, 연락처) 불일치 여부
- 금액 및 날짜 오탈자
- 표 양식이나 단위 오류

4. 출력 형식 지정: "오류 위치 / 수정 전 / 수정 후 / 사유를 표로 정리해줘."

이렇게 구체적으로 지시하면 오류만 쏙쏙 골라내서 표로 만들어 준다.

확실히 작업 시간이 90% 이상 줄어드는 게 체감된다.
퇴근 시간이 달라지더라.
