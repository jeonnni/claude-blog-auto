# 코딩 1도 몰라도 30분 만에 AI로 2D 미니 게임 만드는 법

## 제목 후보
1. 코딩 1도 몰라도 30분 만에 AI로 2D 미니 게임 만드는 법
2. 챗GPT로 만드는 나만의 미니 게임 (노코딩 입문 가이드)
3. 비개발자가 30분 만에 웹 게임 하나 뚝딱 만들어낸 노하우

코딩 까막눈이어도 진짜 30분이면 나만의 웹 게임을 만들 수 있더라.

예전에는 게임 하나 만들려면 프로그래밍 언어부터 배워야 했다.
근데 요즘은 AI 툴만 잘 써도 실행 가능한 2D 미니 게임이 바로 나온다.

개발 지식 전혀 없는 왕초보 기준으로 제일 쉬운 방법을 정리해봤다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261115-0229-1-30-ai-2d-diagram.png)
`사진 파일: 20261115-0229-1-30-ai-2d-diagram.png`

우선 어떤 순서로 진행되는지 전체적인 흐름부터 보자.

아이디어 구상부터 완성까지 생각보다 단계가 아주 단순하다.
우리가 할 일은 거창한 코드 작성이 아니라 AI에게 구체적으로 지시하는 거다.

핵심은 한 줄짜리 명령이 아니라 꽤 상세한 프롬프트를 넣는 거다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261115-0229-1-30-ai-2d-steps.png)
`사진 파일: 20261115-0229-1-30-ai-2d-steps.png`

첫 단계는 챗GPT 같은 대화형 AI에 접속하는 거다.
무료로 쓸 수 있는 기본 AI 서비스로도 충분하다.

대화창에 이렇게 입력해보자.

"HTML5 Canvas로 동작하는 2D 장애물 피하기 게임 코드를 작성해 줘."
"플레이어는 키보드 방향키로 움직이고 상단에서 장애물이 떨어진다."
"부딪히면 게임 오버가 되고 점수가 표시되게 해줘."
"HTML, CSS, 자바스크립트 코드를 파일 하나로 합쳐서 작성해 줘."

이렇게 요청하면 AI가 알아서 한 덩어리의 코드를 짜준다.

코드가 다 나오면 전체 복사를 하자.
메모장을 열고 붙여넣은 뒤 파일 이름을 game.html로 저장한다.

저장한 파일을 마우스로 두 번 클릭해서 웹 브라우저로 열어보자.
키보드 방향키를 누르는 순간 내가 만든 게임이 짠하고 실행된다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261115-0229-1-30-ai-2d-compare.png)
`사진 파일: 20261115-0229-1-30-ai-2d-compare.png`

기존 방식으로 게임을 만드는 것과 AI를 쓰는 방식은 차이가 크다.

문법을 몰라도 문장으로 지시하니까 속도가 비교가 안 된다.
버그가 나도 당황할 필요가 없다.

게임이 멈추거나 동작을 안 하면 실행 화면이나 에러 내용을 그대로 복사해서 AI에게 던지면 된다.
"이 부분에서 동작이 안 되는데 수정해 줘" 하면 알아서 고쳐주더라.

점수판 디자인을 바꾸거나 캐릭터 속도를 올리는 것도 한 줄 요청이면 끝난다.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20261115-0229-1-30-ai-2d-summary.png)
`사진 파일: 20261115-0229-1-30-ai-2d-summary.png`

정리하자면 세 가지만 기억하면 된다.

첫째, 결과물을 한 파일로 받기.
둘째, 이상하면 AI한테 고쳐달라고 떼쓰기.
셋째, 메모장에 붙여넣고 html 파일로 저장하기.

오늘 퇴근하고 딱 30분만 투자해보자.
내 손으로 만든 게임을 직접 플레이하는 재미가 쏠쏠하다.
