## 본문

공공기관 사이트에서 다운받은 파일 열었다가 당황한 적 있을 거다.

글자는 죄다 외계어로 깨져 있고, 중간중간 빈칸도 텅텅 비어 있는 상황.

![대표 이미지](https://jeonnni.github.io/claude-blog-auto/images/20261007-0211-ai-thumbnail-sq.png)

일일이 손으로 수정하다 보면 한 시간은 우습게 날아간다.

근데 요즘은 AI에 프롬프트만 잘 입력하면 1분 만에 싹 정리된다.

복잡한 알고리즘이나 코딩 몰라도 된다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20261007-0211-ai-diagram.png)
`사진 파일: 20261007-0211-ai-diagram.png`

보통 인코딩이 깨진 엑셀이나 텍스트는 유니코드 문제인 경우가 많다.

여기에 데이터 누락까지 겹치면 보고서 만들 때 진짜 머리 아픈데.

AI 데이터 정제 과정을 거치면 깔끔한 표로 바로 바꿔준다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20261007-0211-ai-compare.png)
`사진 파일: 20261007-0211-ai-compare.png`

핵심은 질문을 그냥 던지지 말고 역할을 지정해 주는 거다.

내가 자주 쓰는 데이터 정제 프롬프트 공유해 본다.

```
[프롬프트 예시]
너는 데이터 전처리 전문가야.
아래 텍스트는 인코딩이 깨지고 빈칸이 많은 공공데이터야.
1. 깨진 한글 문자를 원래 의미에 맞게 복원해 줘.
2. 누락된 값(빈칸)은 앞뒤 문맥을 고려해 '미상' 또는 적절한 추정값으로 채워줘.
3. 최종 결과는 깔끔한 Markdown 표 형식으로 출력해 줘.
```

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20261007-0211-ai-steps.png)
`사진 파일: 20261007-0211-ai-steps.png`

방법은 의외로 간단하다.

깨진 텍스트나 엑셀 내용을 복사해서 프롬프트 하단에 붙여넣기만 하면 끝이다.

AI가 문맥을 파악해서 외계어를 한글로 찰떡같이 바꿔준다.

누락된 카테고리나 날짜 형식도 일정하게 통일해 주더라.

결과물로 나온 표는 엑셀에 그대로 붙여넣으면 즉시 데이터 분석이나 보고서에 쓸 수 있다.
