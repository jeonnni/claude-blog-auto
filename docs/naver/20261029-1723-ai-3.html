외주 작업 끝내고 대금 지급 미뤄진 적 다들 한번쯤 있을 거다.
계약서 쓸 때 자세히 안 보고 그냥 서명해서 그렇다.
법률 용어가 너무 어렵고 길어서 대충 넘어가게 되더라.
하지만 요즘은 AI한테 계약서 파일 넣고 질문 몇 개만 던지면 위험한 독소조항을 알아서 다 찾아준다.
챗GPT나 클로드 같은 서비스에 계약서 텍스트를 그대로 붙여넣으면 된다.

핵심은 프롬프트를 얼마나 구체적으로 짜느냐다.
그냥 "이 계약서 문제 있어?" 라고 물어보면 뻔한 답변만 돌아온다.
역할을 지정해주고 정확한 검토 기준을 제시해야 진짜 숨겨진 불리한 조항이 보인다.
직접 써보고 효과 본 프롬프트 구성을 공유해본다.
사진 3

사진 저장
일반적으로 질문할 때랑 역할 지정 후 검토할 때 결과 차이가 상당하다.
그냥 물어보면 일반적인 법률 조언 수준으로 끝나는데.
조건을 정해주면 독소조항 항목별로 수정 요구안 문장까지 바로 만들어준다.
내가 쓰는 프롬프트는 딱 이 틀로 입력한다.
"너는 프리랜서 전문 변호사야. 아래 계약서에서 프리랜서에게 독소조항이 되는 문구를 찾아줘. 무제한 수정 요구, 저작권 전면 양도, 대금 지연 지급, 과도한 손해배상 조항을 우선 검토해줘. 찾아낸 조항마다 위험 이유와 함께 상대방에게 제출할 수정 요구안 조항도 작성해줘."

사용법도 아주 단순하다.
첫째, 계약서 전체 텍스트를 복사해서 붙여넣는다.
둘째, 위 프롬프트를 함께 입력해서 실행한다.
셋째, AI가 뽑아준 독소조항 목록과 수정 요구안을 확인한다.
이렇게 나오는 수정 요구안을 클라이언트에게 메일이나 카톡으로 보내면 된다.
싸우지 않고 정당하게 수정 요청할 명분이 생긴다.
