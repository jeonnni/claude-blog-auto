# 챗GPT 캔바 연동으로 카드뉴스 10분 만에 만들기

## 제목 후보
1. 챗GPT 캔바 연동으로 카드뉴스 10분 만에 만들기
2. 디자이너 없이 SNS 카드뉴스 뚝딱 만드는 AI 활용법
3. 챗GPT와 캔바로 끝내는 초간단 카드뉴스 제작 루틴

매번 SNS 카드뉴스 만들 때마다 기획하고 글 쓰고 디자인까지 하려니 머리가 아팠다.

디자이너가 없는 1인 크리에이터나 담당자라면 다들 공감할 거다.

요즘은 AI 조합으로 몇 분 만에 뚝딱 만드는 방법이 있더라.

챗GPT로 내용을 뽑고 캔바(Canva)로 넘겨서 일괄로 돌려버리는 방식이다.

직접 써보니 작업 시간이 대폭 줄어들어서 공유해본다.

![동작 구조 다이어그램](https://jeonnni.github.io/claude-blog-auto/images/20260907-1620-gpt-10-diagram.png)
`사진 파일: 20260907-1620-gpt-10-diagram.png`

전체적인 흐름은 생각보다 훨씬 간단하다.

주제 정하기부터 카피 작성, 템플릿 대입까지 한 줄기로 연결된다.

핵심은 챗GPT에서 나온 결과물을 캔바의 일괄 작업 기능에 밀어 넣는 거다.

우선 챗GPT를 열고 프롬프트를 이렇게 던져보자.

"SNS 홍보용 5장 카드뉴스 기획해줘."
"표 형태로 [페이지, 헤드라인, 본문] 칼럼 나눠서 작성해줘."

이렇게 요청하면 데이터로 옮기기 딱 좋은 표 형태로 깔끔하게 뽑아준다.

![비교표](https://jeonnni.github.io/claude-blog-auto/images/20260907-1620-gpt-10-compare.png)
`사진 파일: 20260907-1620-gpt-10-compare.png`

예전에는 템플릿 하나에 텍스트 하나씩 복사해서 붙여넣고 위치 맞추느라 시간 다 보냈다.

오타라도 나면 일일이 수정하느라 은근히 번거로웠는데.

AI를 활용해서 대량 생성 기능을 써보니 수작업할 이유가 전혀 없더라.

디자인 감각이 없어도 템플릿만 잘 골라두면 고퀄리티로 완성된다.

![단계별 가이드](https://jeonnni.github.io/claude-blog-auto/images/20260907-1620-gpt-10-steps.png)
`사진 파일: 20260907-1620-gpt-10-steps.png`

실제 제작 순서는 딱 세 단계다.

1. 챗GPT가 만든 표 데이터를 복사한다.
2. 캔바에서 마음에 드는 카드뉴스 템플릿을 하나 연다.
3. 왼쪽 앱 메뉴에서 '일괄 작성'을 찾아 데이터를 넣고 텍스트 상자와 연결한다.

페이지 생성 버튼만 누르면 5장짜리 카드뉴스가 순식간에 들어찬다.

어색한 폰트 크기나 줄바꿈만 살짝 다듬어주면 끝이네.

![핵심 요약](https://jeonnni.github.io/claude-blog-auto/images/20260907-1620-gpt-10-summary.png)
`사진 파일: 20260907-1620-gpt-10-summary.png`

이제 디자이너 없다고 콘텐츠 제작 미룰 필요가 없다.

주제 기획부터 카피, 디자인 배치까지 10분이면 충분하다.

매번 카드뉴스 만들 때마다 스트레스받았다면 이 루틴대로 꼭 한번 해봐라.

퇴근 시간이 확실히 빨라진다.
