막상 기사님 오셔서 전원 다시 켜거나 버튼 몇 개 누르고 해결되면 좀 허무하더라.

근데 그냥 사진만 덜렁 올리면 AI도 대충 답변해준다.

1. 에러 화면 찍기
깜빡이는 불빛이나 디스플레이 에러 코드가 잘 보이게 찍는다.

3. 안내대로 조치하기
안전 지침부터 확인하고 가볍게 조치해본다.
